# MONARCH SYSTEM – Habit Tracker

## Run the app
1. Extract the ZIP.
2. Open the `monarch_system` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.
4. Complete quests, add your own quests, and earn XP.

## Files
- `index.html` – page structure
- `style.css` – dark neon system interface
- `script.js` – quests, XP, levels, streak, and LocalStorage

## Notes
- Data is saved in this browser using LocalStorage.
- Clearing browser site data will erase this local save.
- This is version 1; it does not yet sync between devices or include accounts.
